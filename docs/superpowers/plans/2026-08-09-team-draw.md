# 팀/그룹 뽑기 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `index.html`(단일 파일 앱)에 참가자를 여러 팀으로 자동 배분하는 "팀 나누기" 기능을 추가한다. 성별·신체능력(상/중/하) 균형 배분을 독립적인 옵션으로 지원하며, 신체능력 등급은 참가자 명단/결과 화면에는 노출하지 않는다.

**Architecture:** 배분 알고리즘(셔플, 계층화, 라운드로빈)은 DOM에 의존하지 않는 순수 함수로 새 파일 `team-draw-logic.js`에 분리하고, `index.html`의 인라인 스크립트가 이를 전역(`window.TeamDrawLogic`)으로 불러와 사용한다. 이렇게 분리하면 로직만 Node.js 내장 테스트 러너로 자동 테스트할 수 있고, `index.html`은 기존과 동일하게 빌드 없이 동작한다. DOM/상태 배선(설정 UI, 결과 모달, 히스토리)은 기존 파일의 패턴(전역 `state`, `dom` 캐시 객체, `saveState`)을 그대로 따른다.

**Tech Stack:** 순수 HTML/CSS(Tailwind CDN)/바닐라 JS, Node.js 내장 테스트 러너(`node:test`, `node:assert/strict`) — 새 의존성/빌드 도구 추가 없음.

## Global Constraints

- 신체능력 등급(`ability`)은 참가자 리스트(`renderParticipants`)와 팀 배분 결과 화면(팀 카드) 어디에도 표시하지 않는다. 오직 "등급 관리" 모달에서만 보인다.
- 팀 모드에서는 `1회성 제외 모드` 토글을 비활성화한다.
- 팀 개수는 항상 2 이상, 참가자 수 이하로 클램프/검증한다.
- 균형 배분 체크박스가 켜져 있어도 성별/등급이 `null`인 참가자는 에러 없이 "미지정" 그룹으로 처리한다.
- 팀 이름은 `1팀, 2팀, ...` 숫자로 고정한다(커스터마이징 없음).
- 참고 스펙 문서: `docs/superpowers/specs/2026-08-09-team-draw-design.md`

```js
// team-draw-logic.js
// 팀 나누기 순수 로직. DOM에 의존하지 않으며 브라우저(<script> 전역)와 Node.js(CommonJS) 양쪽에서 동작한다.
(function (global) {
    'use strict';

    function shuffle(arr, rng) {
        rng = rng || Math.random;
        const result = arr.slice();
        for (let i = result.length - 1; i > 0; i--) {
            const j = Math.floor(rng() * (i + 1));
            const tmp = result[i];
            result[i] = result[j];
            result[j] = tmp;
        }
        return result;
    }

    const ABILITY_MAP = {
        '상': '상', '중': '중', '하': '하',
        'high': '상', 'mid': '중', 'medium': '중', 'low': '하',
        'h': '상', 'm': '중', 'l': '하'
    };

    function mapAbilityValue(raw) {
        if (raw === null || raw === undefined) return null;
        const key = String(raw).trim().toLowerCase();
        return ABILITY_MAP[key] || null;
    }

    function clampTeamCount(count, participantCount) {
        const max = Math.max(participantCount, 0);
        let n = Math.floor(Number(count));
        if (!Number.isFinite(n)) n = 2;
        if (max < 2) return max;
        if (n < 2) return 2;
        if (n > max) return max;
        return n;
    }

    function resolveTeamCount(teamSettings, participantCount) {
        if (teamSettings.splitBy === 'size') {
            const size = Math.max(1, Math.floor(Number(teamSettings.teamSize) || 1));
            return Math.ceil(participantCount / size);
        }
        return Math.floor(Number(teamSettings.teamCount) || 2);
    }

    function strataKey(participant, options) {
        options = options || {};
        const parts = [];
        if (options.balanceGender) parts.push(participant.gender || '_');
        if (options.balanceAbility) parts.push(participant.ability || '_');
        return parts.length > 0 ? parts.join('-') : '_';
    }

    function groupIntoStrata(participants, options) {
        const groups = {};
        participants.forEach(p => {
            const key = strataKey(p, options);
            if (!groups[key]) groups[key] = [];
            groups[key].push(p);
        });
        return groups;
    }

    function distributeTeams(participants, teamCount, options) {
        options = options || {};
        const rng = options.rng || Math.random;
        const teams = [];
        for (let i = 0; i < teamCount; i++) {
            teams.push({ name: `${i + 1}팀`, members: [] });
        }

        const groups = groupIntoStrata(participants, options);
        let teamPointer = 0;
        Object.keys(groups).forEach(key => {
            const shuffled = shuffle(groups[key], rng);
            shuffled.forEach(p => {
                teams[teamPointer % teamCount].members.push(p.name);
                teamPointer++;
            });
        });

        return teams;
    }

    const api = { shuffle, mapAbilityValue, clampTeamCount, resolveTeamCount, strataKey, groupIntoStrata, distributeTeams };

    if (typeof module !== 'undefined' && module.exports) {
        module.exports = api;
    } else {
        global.TeamDrawLogic = api;
    }
})(typeof window !== 'undefined' ? window : globalThis);
```

```js
        const extractParticipantsFromCSV = (text) => {
            const rows = parseCSV(text);
            if (rows.length === 0) return [];

            const header = rows[0].map(h => h.trim());
            const nameColIdx = header.findIndex(h => h === '성명' || h === '이름' || h.toLowerCase() === 'name');
            const genderColIdx = header.findIndex(h => h === '성별' || h.toLowerCase() === 'gender');
            const abilityColIdx = header.findIndex(h => h === '등급' || h === '신체능력' || h.toLowerCase() === 'ability');

            let dataRows, colIdx;
            if (nameColIdx !== -1) {
                dataRows = rows.slice(1);
                colIdx = nameColIdx;
            } else if (header.length === 1) {
                // 헤더 없이 한 줄에 이름 하나씩 있는 단순 목록으로 간주
                dataRows = rows;
                colIdx = 0;
            } else {
                return null; // 이름 컬럼을 찾을 수 없음
            }

            const seen = new Set();
            const participants = [];
            dataRows.forEach(r => {
                const name = (r[colIdx] || '').trim();
                if (!name || seen.has(name)) return;
                seen.add(name);
                const genderRaw = genderColIdx !== -1 ? (r[genderColIdx] || '').trim().toLowerCase() : '';
                const abilityRaw = abilityColIdx !== -1 ? (r[abilityColIdx] || '') : '';
                participants.push({ name, gender: GENDER_MAP[genderRaw] || null, ability: TeamDrawLogic.mapAbilityValue(abilityRaw) });
            });
            return participants;
        };
```

```js
            dom.resultTitle.style.display = 'none';
            dom.resultTeams.classList.remove('hidden');
            dom.resultTeams.innerHTML = teams.map(team => `
                <div class="bg-white/10 backdrop-blur rounded-2xl p-5 text-left">
                    <p class="text-white font-black text-xl mb-3">${team.name}</p>
                    <ul class="space-y-1">
                        ${team.members.map(name => `<li class="text-white/90 font-semibold text-base">${name}</li>`).join('')}
                    </ul>
                </div>
            `).join('');

            dom.continueDraw.style.display = 'none';
            dom.exportTeamCsv.style.display = 'flex';

        const isTeamMode = () => state.settings.genderMode === 'team';

        const runTeamDraw = () => {
            if (state.participants.length < 1 || isRolling) return;

            const ts = state.settings.teamSettings;
            const rawCount = TeamDrawLogic.resolveTeamCount(ts, state.participants.length);

            if (rawCount < 2 || rawCount > state.participants.length) {
                showToast('참가자 수보다 팀이 많을 수 없습니다.', 'error');
                return;

            initAudio();

            const teams = TeamDrawLogic.distributeTeams(state.participants, rawCount, {
                balanceGender: ts.balanceGender,
                balanceAbility: ts.balanceAbility
            });
            lastTeamResult = teams;

            const now = new Date();
            state.history.unshift({ id: Date.now(), type: 'team', teamCount: teams.length, date: now.toLocaleString(), dayKey: toDayKey(now), teams });
            saveState('history');
            renderHistoryList();

            renderTeamResultOverlay(teams);
            playSound('success');
            fireConfetti();
        };

        dom.exportTeamCsv.addEventListener('click', () => {
            if (!lastTeamResult) return;
            const lines = ['팀,이름'];
            lastTeamResult.forEach(team => {
                team.members.forEach(name => lines.push(`${team.name},${csvField(name)}`));
            });
            const csvContent = '﻿' + lines.join('\n');
            const blob = new Blob([csvContent], { type: 'text/csv;charset=utf-8;' });
            const url = URL.createObjectURL(blob);
            const today = new Date().toISOString().slice(0, 10).replace(/-/g, '');
            const a = document.createElement('a');
            a.href = url;
            a.download = `팀배분_${today}.csv`;
            a.click();
            URL.revokeObjectURL(url);
            showToast('팀 배분 결과를 내보냈습니다.', 'success');
        });
```
